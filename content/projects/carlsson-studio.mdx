## Problem

Business owners often know they need software, but struggle to translate operational problems into technical requirements. Traditional contact forms collect little context, leading to lengthy discovery meetings before a suitable solution can even be proposed. At the same time, many software projects begin from scratch despite sharing similar operational foundations.

## Solution

Carlsson Studio replaces the traditional portfolio with an interactive software discovery platform. Through an AI-assisted questionnaire, businesses describe their operations, challenges, and objectives. The platform analyzes these requirements and recommends the most suitable software foundation from Carlsson Studio's growing ecosystem, generating a tailored implementation roadmap instead of a generic contact request.

## Architecture

The platform follows a modern frontend-backend architecture. A Next.js frontend provides an interactive discovery experience, while a Java Spring Boot backend manages project questionnaires, business rule evaluation, foundation matching, proposal generation, and future client management capabilities. The recommendation engine operates on structured metadata collected from every software foundation, allowing the platform to evolve as new projects are added.
