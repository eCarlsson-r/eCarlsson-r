## Project Overview
A modern platform for managing tenants, leases, and payments.

**Business Problem**  
Property owners need structured systems to manage operations efficiently.

**Key Capabilities**
- Tenant management
- Lease tracking
- Payment management
- Admin dashboard

---

## Architecture Overview
SPA frontend + backend API.

**Technology Stack**
Backend: Laravel  
Frontend: Inertia Vue  
Infrastructure: Google Cloud, AlloyDB  

---

## Domain Complexity
Managing financial data and relational entities.

---

## Key Engineering Challenges
**Challenge:** Handling relational data  
**Solution:** Structured schema  
**Outcome:** Scalable system  

---

## Design Decisions
Modern Laravel + SPA approach.
