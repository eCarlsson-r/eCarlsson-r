## Project Overview
An admin portal for managing insurance policies, client records, and operational workflows.

**Business Problem**  
Insurance operations require structured data handling, policy tracking, and scalable administrative workflows.

**Key Capabilities**
- Policy management
- Client records system
- Role-based workflows
- Admin dashboard

---

## Architecture Overview
**System Structure**
- Backend: Laravel API
- Frontend: React via Inertia

**Technology Stack**
Backend: Laravel, MySQL  
Frontend: Inertia, React  
Infrastructure: Web deployment  

---

## Domain Complexity
Insurance systems involve relational data, lifecycle tracking, and structured workflows across multiple entities.

---

## Key Engineering Challenges
**Challenge:** Managing structured policy relationships  
**Solution:** Clear relational modeling  
**Outcome:** Scalable and maintainable data structure  

---

## Design Decisions
Used Inertia to balance SPA experience with Laravel backend simplicity.

---

## What Makes This Project Unique
Focus on structured business workflows rather than generic admin CRUD.

---

## Lessons Learned
- Importance of data modeling  
- Managing workflow states
