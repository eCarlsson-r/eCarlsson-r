## Business Situation

A Human Design practice producing written personality and business compatibility analyses for clients, each one derived from that client's birth-chart data.

## Operational Challenge

Every report was interpreted point by point and written by hand. The work was slow, it came out inconsistent between reports because the result depended on who wrote it and when, and it capped the practice at the number of clients one person could physically write for.

## Solution

HumanDesign computes the client's full chart from birth data using precise calculation logic, then generates a readable, personalized written analysis from that computed chart — including business compatibility insights.

## Business Impact

Reports that took hours per client are produced immediately, and consistently, because each one is generated from the same calculated chart rather than a fresh interpretation. The practice's capacity stops being limited by writing time. The project placed Top 30 in the Nusantara Elevate AI Talent Challenge.

## Architecture

An ASP.NET Core API with MySQL performs the deterministic chart calculations — the non-negotiable, precision-critical core of the domain — while an Angular frontend (with AnalogJS) renders the interactive chart and reports. The AI generation layer consumes the computed chart data, not raw user input, so written analyses stay grounded in the calculated results.
