## Project Overview

An AI-powered Human Design platform that automates chart generation, personalized report delivery, and client management through an integrated CRM and CMS ecosystem.

Selected as one of the **30 Karya Terpilih (Top 10 – Kategori 3: Innovation with AI)** in the AI Talent Challenge Nusantara by Elevate.

The platform transforms complex Human Design calculations into scalable digital workflows for practitioners, agencies, and consultation businesses.

---

## Business Problem

Human Design consultations are traditionally manual, difficult to scale, and heavily dependent on practitioner interpretation.

Most practitioners struggle with:
- Generating accurate charts consistently
- Delivering structured client reports
- Managing leads and consultations
- Scaling personalized insight delivery
- Monetizing premium interpretation workflows

This project addresses those limitations by combining automated calculation logic, AI-assisted interpretation workflows, CRM management, and structured report delivery into a unified platform.

## Domain Complexity

* Complex transformation of birth data into structured chart outputs
* Mapping abstract Human Design concepts (gates, channels, centers) into data models
* Synchronizing calculated results with CMS-driven interpretation content
* Multi-role data access (CRM hierarchy: Admin → Leader → Agent → User)

---

## Key Engineering Challenges

**Challenge:** Rendering dynamic bodygraph visualization  
**Solution:** Built a custom SVG rendering engine that maps gates, channels, and centers dynamically  
**Outcome:** Accurate and interactive chart visualization aligned with computed data

**Challenge:** Managing tiered report access (Preview / Summary / Detail)  
**Solution:** Designed access control logic tied to purchase state and user role  
**Outcome:** Seamless upgrade flow without duplicating report data

**Challenge:** Avoiding blocking queries in role-based filtering  
**Solution:** Refactored async role resolution to avoid `.Result` in LINQ queries  
**Outcome:** Eliminated deadlocks and improved API reliability

---

## Key Design Decisions (Selected)

* Used **SSR (AnalogJS)** to improve initial load and SEO for public pages
* Chose **REST API architecture** for predictable integration across multiple frontend sections
* Centralized report logic to avoid duplication between preview and paid versions

## What Makes This Project Unique

This project combines several difficult engineering domains into a single production-oriented platform:

- Non-standard metaphysical calculation systems
- AI-assisted interpretation workflows
- Dynamic SVG visualization rendering
- CRM and referral management
- CMS-driven content architecture
- Tiered monetization flows

The biggest challenge was translating abstract Human Design concepts into deterministic software models that could be rendered visually, interpreted structurally, and managed commercially at scale.

Unlike typical CRUD applications, this platform required custom domain modeling, visualization logic, and interpretation orchestration across multiple subsystems.

---

## Lessons Learned

* Domain modeling is critical for non-standard problem spaces
* Separating calculation logic from presentation improves scalability
* Role-based systems require careful query design to avoid performance issues
