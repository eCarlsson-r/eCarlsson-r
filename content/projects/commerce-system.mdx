## Project Overview
An end-to-end retail system with admin, POS, and storefront applications.

**Business Problem**  
Retail businesses need integrated systems for transactions, inventory, and customer-facing sales.

**Key Capabilities**
- POS system
- Inventory tracking
- Storefront interface
- Admin management

---

## Architecture Overview
**System Structure**
- Backend API
- POS interface
- Storefront

**Technology Stack**
Backend: Laravel  
Frontend: Angular, Next.js  
Infrastructure: Multi-app
